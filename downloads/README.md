# GATENOVA Android download

Requires Android 8.0 or newer. Open the APK on your phone and follow the installation prompts. See [INSTALL.md](INSTALL.md) for details and [SHA256SUMS.txt](SHA256SUMS.txt) to verify the download.

This directory is a versioned distribution channel for the current core Android app. Version 1.2.0 adds a refined interface, Light/Dark/System appearance and a mobile study toolbar. It includes all 2027 syllabuses and an in-app reader for official papers and keys, alongside the offline experience and local Nova lesson guide. Signing keys and passwords are never included. Future updates must keep the same application ID and signing certificate.
